# הסל שלנו

אפליקציית רשימת קניות משפחתית בעברית. גרסת הפרסום נמצאת ב־docs/; קוד המקור ב־src/.

פרסום: Settings > Pages > Deploy from a branch > main > /docs.

מסד Supabase הוקם, שבע הטבלאות נוצרו ושני משתמשים מורשים נוספו. בדיקות SQL עם שתי זהויות מדומות עברו; בדיקות התחברות וסנכרון דרך דפדפנים עדיין נדרשות. אין להריץ שוב את סכמת המסד על הפרויקט הקיים.

Keep Alive: ראו .github/workflows/keep-alive.yml. יש להגדיר את SUPABASE_URL ו-SUPABASE_PUBLISHABLE_KEY כ-Repository Variables. אין להשתמש במפתח שרת.

הקוד ציבורי, הנתונים מוגנים באמצעות הרשאות בצד השרת. אין להעלות סיסמאות, קובצי נתונים או ייצוא.

הוראות נוספות ב-README-GITHUB.md; שלבי הקמת המסד והמשתמשים המופיעים בו כבר בוצעו.
